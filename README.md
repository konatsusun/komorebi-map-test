# こもれび近隣マップ（テスト版）

名護市営市場周辺の地図表示を確認する静的な試作品です。こもれび以外の4件は架空のデモです。地図上で位置を編集する機能は含みません。

地図の読み込みはOpenFreeMapへ接続します。経路ボタンはGoogleマップ、公式ホームページボタンは店舗サイトを別タブで開きます。
